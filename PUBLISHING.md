# Publishing

Fastest GitHub upload path:

1. Create a new public repository named `graph-kiln`
2. Leave README, license, and .gitignore unchecked during repo creation
3. Unzip this package locally
4. Upload the **contents** of the folder, not the zip itself
5. Commit with `Initial release`

Recommended repo description:

`Browser-native local-first graph reasoning workspace with offline storage, WebAssembly scoring, worker clustering, replay, and optional WebGPU compute.`

Before publishing, update these if needed:
- `package.json` homepage / repository URLs
- `index.html` `codeRepository`
- any org or username placeholders
