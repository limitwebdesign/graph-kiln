# GraphKiln roadmap

## v1
- single workspace
- note and link nodes
- local persistence
- export / import JSON

## v2
- code and image nodes
- action log
- inspector

## v3
- inferred links and graph rendering
- keyword clustering
- auto-layout

## v4
- replay timeline
- search and filters
- suggestion engine

## v5
- service worker and PWA shell
- installable app manifest

## v6
- WebAssembly scoring core
- related-node ranking

## v7
- cluster worker off the main thread
- larger-workspace responsiveness improvements

## v8
- optional WebGPU benchmark and compute hooks
- better runtime capability inspection

## v9
- multi-workspace import / merge
- deterministic merge semantics and portable workspace packs

## v10
- unified static graph reasoning cockpit
- replay + merge + compute in one dependency-light build
- clean extension points for later sync or on-device model adapters

## v11
- brand reset after collision review
- identity metadata hardening
- packaging cleanup for public GitHub release
- publishing docs and name-check notes

## Beyond v11
- authenticated device sync
- true CRDT backend such as Automerge
- optional ONNX / Transformers.js adapter pack
- browser file system integration
- graph snapshots and version compare
- collaborative cursor and presence layer
- encrypted workspace packs
